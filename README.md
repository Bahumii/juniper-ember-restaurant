# Juniper & Ember — Restaurant Landing Page

A responsive, single-page restaurant website built with semantic HTML5 and plain CSS3. No frameworks or build tools are required.

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a browser.

## What's included
- Hero section with a reservation call to action
- Menu grouped into starters, mains and desserts
- Restaurant story/about section
- Reservation contact links
- Footer with hours, location and contact details
- Semantic landmarks, one `h1`, skip link and visible keyboard focus
- CSS custom properties, global `box-sizing: border-box`, Flexbox and CSS Grid
- Responsive layouts for phone, tablet and desktop

## Before publishing
This is a design/demo site. Replace the fictional restaurant details before using it for a real business:
- Address and opening hours
- Telephone number and email address
- Reservation email (currently a `mailto:` link)
- Sample menu and prices
- Example map destination

Images are loaded from Unsplash and Google Fonts are imported remotely, so those assets require an internet connection. The page itself has no JavaScript dependencies.
